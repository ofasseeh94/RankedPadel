# RankedPadel

RankedPadel is an early beta concept for a web-based padel ranking and match coordination platform.

## Current Prototype

The currently testable prototype is a standalone static file:

- `rankedpadel-beta-static/index.html`

It includes:

- public landing page
- signup and login prototype flow
- player dashboard
- create game flow with Team 1 / Team 2 right-left positions
- find open games with filters
- post-game score confirmation
- admin court and player data view
- private placement scoring logic
